# Acuario - Bootcamp SQL 

## Creado por Allan Benavides
En este repositorio se consolidan todos los entregables, talleres y retos técnicos asignados durante el desarrollo del bootcamp de SQL, estructurados por semanas temáticas según el dominio y requerimientos estipulados.

---

## 📂 Estructura del Proyecto

El código fuente y los scripts de base de datos se organizan bajo el estándar de paquetes dentro del directorio `Src/co/edu/sena`, dividiéndose en módulos semanales independientes:

* **`week-06-funciones_de_agregacion/`**: Uso de funciones de agregación (`SUM`, `AVG`, `COUNT`, `MIN`, `MAX`) y agrupación de datos con `GROUP BY` y `HAVING`.
* **`week-07-null_y_constraints/`**: Gestión de valores nulos (`IS NULL`, `COALESCE`) y aplicación de restricciones de integridad (`NOT NULL`, `UNIQUE`, `CHECK`, `FOREIGN KEY`).
* **`week-08-proyecto_integrador_etapa_0/`**: Modelado inicial, diseño de esquemas y base estructural del proyecto integrador.
* **`week-09-joins_inner_join_y_left_join/`**: Consultas relacionales combinando múltiples tablas mediante `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN` y `FULL OUTER JOIN`.
* **`week-10-cross_join_y_self_join/`**: Implementación de productos cartesianos y relaciones autorreferenciales (`SELF JOIN`) para estructuras jerárquicas o combinatorias.
* **`week-11-subqueries/`**: Construcción de subconsultas correlacionadas y no correlacionadas en cláusulas `SELECT`, `FROM` y `WHERE`.
* **`week-12-ctes_y_case_when/`**: Expresiones de tabla comunes (CTEs) estándar para organizar consultas complejas y lógica condicional mediante `CASE WHEN`.
* **`week-13-ctes_recursivas/`**: Consultas jerárquicas avanzadas mediante `WITH RECURSIVE` para recorrer taxonomías y árboles de datos de forma dinámica.
* **`week-14-window_functions_ranking/`**: Aplicación de funciones de ventana analíticas (`ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`) para resolver problemas de particionamiento, eliminación de duplicados y reportes de posiciones/Top-N por categorías.
